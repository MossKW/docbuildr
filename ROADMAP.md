The roadmap is intended as a guideline rather than a strict release schedule.

# Project Principles

DocBuildr follows several principles.

- Simplicity first
- Beautiful output
- Offline friendly
- Documentation focused
- Minimal configuration
- Clean architecture
- Easy to contribute

---

# Release Philosophy

New features are developed in small bundles.

Each bundle must satisfy the following requirements.

- Build successfully
- Install successfully
- Runtime test passes
- Working tree is clean
- Changes are committed

This keeps every commit in a deployable state.
